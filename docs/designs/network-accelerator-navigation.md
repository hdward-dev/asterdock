# 网络加速功能导航

右侧固定 88 DIP 导航栏，按顺序提供概览、代理、配置、连接、规则、日志、设置。每项包含图标、文字、提示及选中高亮；支持键盘聚焦和按钮激活。正文独立滚动，切换功能时回到顶部，保留当前节点搜索和连接状态。

- 概览：连接总览、代理／配置／规则快捷入口、核心状态。
- 代理：节点搜索、测速、线路选择、代理方式与 TUN。
- 配置：切换订阅配置、管理与更新订阅、流量和到期信息。
- 连接：连接启停、时长、当前节点、本地代理入口和终端代理命令。
- 规则：当前策略及应用内置规则说明；提供代理方式切换入口。
- 日志：本次会话最近 300 条经过现有日志处理的核心记录，最新记录优先，支持清空显示。
- 设置：代理方式、TUN 和核心安装／状态。

连接页展示当前加速连接及本地入口，不包含逐请求连接列表。规则页说明现有生成策略，不包含规则编辑器。

验证：网络加速模块编译零警告、零错误；原生 Avalonia 预览验证七个导航按钮、唯一选中状态、搜索、窄屏布局、日志数量上限与清空。检查七页浅色截图及概览深色截图。预览数据为示例，未启动真实代理。
