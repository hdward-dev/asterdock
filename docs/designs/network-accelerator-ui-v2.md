# 网络加速界面 v2

本次调整聚焦连接、选线和设置的操作顺序，延续应用现有浅色／深色主题资源。

- 顶部连接总览集中显示状态、操作反馈、当前线路、延迟、连接时长及本地端口；突出开始／停止加速，繁忙时显示进度。
- 主区域左侧提供节点数量、搜索、测速和线路列表；选中线路有背景及单选标记，长名称省略显示。
- 右侧依次放置连接设置、订阅和核心状态；规则／全局／直连提供随选择变化的解释。
- 未添加订阅时引导添加；搜索无结果时支持一键清空。
- 宽度小于 900 时设置移到节点列表下方；小于 620 时连接操作和指标进一步换行。
- 移除没有数据来源的固定上下行速率。流量条展示剩余比例，与“剩余 / 总流量”一致；订阅没有流量数据时隐藏进度条。
- 原有连接、模式切换、TUN、订阅管理、测速、复制终端代理命令、安装核心及日志入口继续使用已有处理逻辑。

验证：模块构建；使用临时原生 Avalonia 预览检查浅色、深色、560 宽窄窗口、未配置及搜索无结果状态。预览使用示例数据，未启动实际代理连接。
