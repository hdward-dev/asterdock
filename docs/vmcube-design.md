# VMCUBE 界面与功能设计

VMCUBE 是星栈内的 KVM 管理轻应用，面向个人实验室和小型服务器运维。遵循星栈共享主题，蓝色主操作、克制的卡片布局、中文状态与可见的操作反馈。

## 页面结构

```text
VMCUBE                              KVM / LIBVIRT
连接 URI [qemu:///system         ] [连接] [演示模式] [直接连接 VNC]
[全部虚拟机] [运行中] [已关闭] [分配内存]
[搜索名称                       ] [状态筛选] [刷新]
┌ 虚拟机列表 ──────────────────┬ 虚拟机详情 ──────┐
│ 名称 / 状态 / vCPU / 内存     │ 名称、UUID、状态 │
│ 点击选中                     │ 配置内存与 CPU   │
│ 空列表有明确提示             │ 启动 / 正常关机  │
│                              │ 连接桌面 / 暂停  │
└──────────────────────────────┴──────────────────┘
操作记录：时间、目标、请求结果；失败原因可见
```

窄窗口将详情放在列表下方，页面整体滚动。统计值为虚拟机数量与配置内存总和，不伪装成主机实时负载。搜索与状态筛选可以组合。

## 首版范围

- 单连接工作区；保存上次成功连接 URI 到应用数据目录，不保存密码。
- 初始为空，用户主动连接；独立演示模式可预览和体验生命周期操作。
- virsh 读取域 UUID、名称、状态、vCPU 和配置最大内存。
- 启动、正常关机、暂停/恢复；正常关机通过页内二次确认，明确可能异步完成。
- 执行期间禁止重复操作，失败后清空过期数据，重新连接后恢复。
- 外部命令异步运行、固定操作白名单、参数列表传参、超时与卸载取消。
- 本机依赖 virsh；远程使用 qemu+ssh URI，需要已有 SSH 密钥及主机信任配置。应用不处理交互密码提示。

## 0.2 内置桌面连接

- 虚拟机详情点击「连接桌面」，通过活动域 XML 自动读取 VNC 监听地址与端口，并在星栈管理的独立控制台窗口显示画面。
- 复用 U远程的托管 VNC 协议、密码认证与键盘映射代码；无需安装 U远程轻应用。
- 支持鼠标、滚轮、键盘、全屏和发送 Ctrl + Alt + Del；Ctrl + Alt + Esc 释放输入。
- qemu+ssh 连接自动创建只监听本机回环地址的 SSH 转发，支持 URI 中的 SSH 端口。关闭控制台或卸载模块会取消连接并结束隧道进程。
- 「直接连接 VNC」可只填写主机、端口和访问密码，不依赖 virsh。需要目标已有 VNC 服务，直接连接应在可信局域网或 VPN 中使用。
- VNC 密码仅在内存中供本次连接使用，不写入配置。自动发现不提取域 XML 中的密码。
- 支持 RFB 3.3/3.7/3.8，无认证或传统 VNC 密码认证。SPICE、TLS/VeNCrypt 与 Unix socket 控制台暂未支持，会提示原因。
- 控制台发现失败保留虚拟机管理连接；连接或认证失败在控制台窗口显示。演示虚拟机不提供假桌面。

### 使用

1. 使用虚拟机列表：输入 `qemu+ssh://user@kvm-host/system` 连接主机，选择已运行虚拟机，按需填写 VNC 密码，点击「连接桌面」。本机需要 virsh 和 OpenSSH，已有 SSH 密钥和主机信任配置。
2. 直接连接：点击「直接连接 VNC」，填写服务器地址、实际 TCP 端口（默认 5900）及 VNC 密码，然后连接桌面。无需安装来宾代理；目标应已配置 VNC 控制台并允许此地址访问。
